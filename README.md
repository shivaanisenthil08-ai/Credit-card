Credit Card Default Prediction

Overview
A Machine Learning project that predicts whether a credit card customer is likely to default on their next payment using customer information and payment history.

Dataset
The project uses the Default of Credit Card Clients dataset, containing customer details, credit limits, billing information, payment history, and default status.

Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook

Machine Learning Models
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

Project Workflow
1. Data loading and exploration
2. Data cleaning and preprocessing
3. Missing value and outlier handling
4. Feature scaling
5. Model training and prediction
6. Performance evaluation

Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
  
How to Run
1. Clone this repository.
2. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn xlrd jupyter
   ```
3. Ensure the dataset file `default of credit card clients.xls` is in the project folder.
4. Open `CreditCard.ipynb` using Jupyter Notebook.
5. Run the cells sequentially.

Project Goal
To compare different classification algorithms and identify a suitable model for predicting credit card payment defaults.
